## 4. v0.19.4 P0/P1/P2 升级方案（深化版 6 维度）

### 4.1 P0 必做（4 项 / 3-4 周 → v0.20.0 之前完成）

#### P0-1：AI 结构化报告自动填充引擎（**对标联影**）

| 维度 | 内容 |
|------|------|
| **现状** | ReportWritePage 2891 行完全靠医生手敲，无 AI 辅助 |
| **目标** | 调用 mockApi 接入"AI 自动生成报告草稿" + "医生仅审核/微调" |
| **接口** | `mockApi.generateStructuredReport(examId)` → `{ findings, diagnosis, impression, confidence, sourceModules }` |
| **实现** | 1. 新建 `src/ai-stream/report-generator/StructuredReportEngine.ts`（300 行）<br>2. 接收 `ExamWorkflow` + `ReportTemplates` → 输出三段式报告<br>3. ReportWritePage 顶部加"AI 生成草稿"按钮（绿色 primary）<br>4. 右侧弹出 AI 建议面板（可全采纳/部分采纳/忽略） |
| **验收** | 1. tsc 0 错<br>2. 浏览器实测：点 AI 按钮 → 3 秒内出现报告草稿<br>3. 医生可编辑/采纳/驳回 3 个选项 |
| **工时** | 1 周 |
| **风险** | AI 草稿质量需 ≥70% 可用率；先做 demo 测试，再用真实数据评估 |

#### P0-2：多模态影像-病理符合率质控（**对标联影/响应 2024 卫健委新规**）

| 维度 | 内容 |
|------|------|
| **现状** | 质控只到"申请单/图像/报告" 3 维度，无病理符合率 |
| **目标** | 新增"影像-病理符合率"质控（卫健委 2024 新规要求）|

| **验收** | 1. 路由可访问<br>2. 卡片显示符合率 % + 不符合案例列表（可点击查看详情）<br>3. tsc 0 错 |

## 关键决策

1. **CSS Modules + 原生 CSS 变量**（首推）：Vite 5 零配置 / 迁移阻力最小 / 无 runtime 开销
2. **不引入 UI 库**：与现状 53 page 100% 内联契合度最高 / 业务语义命名保留
3. **主色 #3b82f6**（主公指定），不用 #6366f1
4. **亮 + 暗 + 跟随系统 三档主题**（首推 2 档 light + dark + 可选 system）
5. **Sidebar 280 → 260 / Topbar 72 → 56**（与主公 design sense 对齐）
